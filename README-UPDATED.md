# Aquilo Thermometer: Updated

Displays temperature information for Aquilo. The Factorio 2.1 version retains saved thermometer state and rendering ownership during migration.

Requires Factorio 2.1.24 or later. Enable the dependencies listed in the mod manager. This fork keeps the original mod’s content rather than introducing a new balance model.

Existing saves using aquilo-thermometer can migrate to this mod identity. Keep a backup when changing a mod set, and disable the original when selecting this fork.

Original mod: [ aquilo-thermometer ](https://mods.factorio.com/mod/aquilo-thermometer). Original author credits and applicable license notices are retained in the source package.
